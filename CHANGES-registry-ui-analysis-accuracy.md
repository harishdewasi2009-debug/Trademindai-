# Registry UI, technical analysis, futures basis, accuracy tracking

**Backend (new):** `utils/technicalAnalysis.js` (ADX trend strength, swing support/resistance, relative volume, volatility state, breakout/breakdown, momentum ROC, transparent rule-based bias with evidence votes + invalidation + risks; returns `ok:false` when <30 real candles), `services/analysisTracker.js` (records each read with frozen success criteria, evaluates only after the horizon candle completes using real Upstox candles, reports accuracy from evaluated rows only), `services/futuresBasis.js` (basis = futures − spot from two Upstox quotes, only when both exist).
**Backend (changed):** `getAnalysisContext` now includes `technical`; `/api/market/registry/analysis-context` records the read; new routes `GET /futures-basis`, `GET /accuracy`, `POST /admin/evaluate`; 30-min evaluation cron; `instrumentAnalysis` prompt now asks for trend, S/R, volatility, conditional scenarios, risks, invalidation (still no advice/targets); `schema.sql` adds `market_analysis_log`; duplicate `upstox-js-sdk` key removed from package.json.
**Frontend (Markets page):** 7-category selector (Indian Stocks, Indian Indices, F&O, Currency, Commodity, Global Indices, Global Indicators) built from live segment data — categories with no instruments in the Upstox master show "UNSUPPORTED BY UPSTOX"; undiscovered extra segments appear under "Other"; option chain + Greeks table (only fields Upstox returned), futures basis table, technical-read panel (works even without an AI plan), global index/indicator data-label box, SMA20 overlay, outcome-tracked accuracy panel (sample size, pending, unresolvable, period, by market/timeframe/bias).
**Tests:** `npm test` → 45 passing (10 new). UI render paths smoke-tested in jsdom against mocked API payloads.

**Not verified (no Upstox token/network in the build sandbox):** every live Upstox response. Run `npm run migrate && npm run audit:upstox` with your credentials to generate the real segment/capability table. Option-chain field names follow Upstox's documented response; if your account's payload differs, the table shows "—" rather than inventing values.
**Not built:** multi-stock comparison view and a market-overview/heatmap page; Greeks/chain are Elite-gated (existing plan rule).
